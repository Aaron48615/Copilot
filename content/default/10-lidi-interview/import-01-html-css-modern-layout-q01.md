# Grid 的 auto-fit 和 auto-fill 有什么区别？

## 核心回答

容器放不满时，auto-fill 会保留空的轨道，auto-fit 会把空轨道折叠，现有卡片可以拉宽。大多数自适应卡片场景用 auto-fit 更符合直觉，但要看是否需要保留网格轨道。
