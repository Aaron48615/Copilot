# Vue 2 和 Vue 3 有什么区别？

## 核心回答

1. Vue 2 常见的是 Options API，代码按配置项组织；Vue 3 可以使用 Composition API，逻辑更容易按功能复用。
2. Vue 3 的响应式实现基于 Proxy，可以直接观察对象和数组的一些变化；Vue 2 使用 `Object.defineProperty`，对新增属性和数组某些操作需要额外处理。
3. Vue 3 的 TypeScript 支持和 `<script setup>` 体验更好，适合我在轻购项目里定义接口数据和组件参数。
4. 这不代表 Vue 2 不能写复杂项目。智服工单里用 Vue 2、Vuex 和路由 meta 一样可以完成分页、权限和工单状态流程，关键是代码结构和边界处理。
