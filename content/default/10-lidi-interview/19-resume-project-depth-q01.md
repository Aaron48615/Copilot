# 你说 GitHub 年度开发记录近千次，主要做了什么？

## 核心回答

1. 这些提交主要来自个人项目和持续迭代，不是单纯刷次数。以轻购为例，里面有页面开发、接口对接、AI 搜索联想、商品详情 AI 卖点、登录跳转、购物车并发保护、订单和地址流程，以及构建和部署问题修复。
2. 我不会只报一个数字，而是会拿一个完整改动来讲。比如购物车数量修改，我从重复点击产生并发请求开始，增加 `updatingBasketIds`，请求传差值，成功后同步数量，数量变成零时走删除接口。
3. AI 相关改动也可以拆开：输入防抖、AbortController、请求编号、五分钟缓存、结果清洗、五条校验和本地降级。这些细节比“用了 AI”更能说明我实际做过什么。
4. 提交次数不能直接代表代码质量，所以我更看重改动是否能说明问题、是否容易回滚、是否经过构建和手动验证。
