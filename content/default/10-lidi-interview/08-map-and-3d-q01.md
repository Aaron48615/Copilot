# 地图组件卸载时需要做什么？

## 核心回答

1. 移除地图相关的事件监听和定时任务，清理标记点、覆盖层和其他动态对象。
2. 如果地图 SDK 提供销毁方法，在组件卸载时调用，避免页面切换后旧实例还占用资源。
3. 对异步数据请求做取消或结果校验，防止用户已经离开页面，旧请求返回以后还修改当前状态。
4. 如果 SDK 的销毁方式不明确，我会查官方文档并通过多次进入退出页面观察内存和实例数量，而不是凭感觉处理。
