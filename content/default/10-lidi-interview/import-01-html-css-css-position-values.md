# position 有哪些值？分别什么场景用？

## 核心回答

1. position 常用值有 static、relative、absolute、fixed 和 sticky，我会从是否参与正常布局以及参照谁来区分。static 是默认状态，top 等偏移不起作用，正文和普通布局通常保持默认即可，不需要每个元素都先设置定位。

2. relative 仍保留原位置，偏移只改变显示位置，常用作角标的定位参照。absolute 退出普通文档流，不给自己保留占位，通常相对最近的定位祖先；但 transform 等属性也能建立包含块，因此“只找最近非 static 祖先”是常见情况，不是完整规则。

3. fixed 也退出正常流，在没有特殊祖先影响时相对视口，适合悬浮入口和固定工具栏。它不会自动给正文腾出空间，而且非 none 的 transform 祖先可能改变其包含块；出现“固定按钮跟着卡片走”时，应检查祖先，而不是仅仅改 z-index。

4. sticky 则在正常位置基础上受到滚动偏移约束，适合目录和表头。它要有 top 等相关方向的阈值，且受滚动容器和包含块边界限制。选择时我会先问这是内容内部吸顶还是全页面固定，再看是否需要占位，避免用复杂监听模拟本来能由 CSS 完成的行为。

5. 一个常见组合是封面图片保持正常布局，右上角角标绝对定位，这样封面负责撑开卡片，角标只负责覆盖。与把图片和所有文字都绝对定位相比，内容变化时需要手动维护的坐标更少，也更符合各元素的职责。

## 追问：relative 位移和 margin 调整有什么区别？

1. relative 的偏移不改变原来的正常布局占位，旁边元素仍按它没有移动时的位置排布。比如一个按钮向右偏移后，左边可能留下原位置的空间，右边则可能覆盖邻居，而不是让整行重新分配空间。

2. margin 参与盒子之间的布局关系，调整它通常会影响相邻内容的位置。不过具体表现还受布局模型和外边距折叠影响，不能简单把 margin 当成另一种 top、left，二者是在不同阶段表达不同需求。

3. 如果只是图标的轻微视觉校正，可以考虑相对定位或变换；如果需求是元素之间保持距离，就使用 gap、margin 或 padding。先分清视觉移动与布局留白，可以避免响应式变化后出现大量难以解释的偏移值。

## 追问：绝对定位四边都写 0 会发生什么？

1. 在常见非替换元素、宽高为 auto 的情况下，左右偏移会共同约束可用宽度，上下偏移约束高度，所以 `inset: 0` 常用于让遮罩覆盖包含块。前提是包含块已经正确建立，而不是误以为它一定覆盖父元素的内容区。

2. 如果又指定了固定宽高，约束就不再是单纯拉伸，浏览器需要按定位规则解决多余约束。已知尺寸配合自动外边距可以用于居中，但要理解具体方向和可用空间，不能把所有属性叠上去期待自动得到想要的位置。

3. 我会在元素面板查看包含块边界、内边距和最终尺寸，并测试内容溢出。覆盖层适合这种写法，正文容器通常不应靠四边定位撑满，否则父级高度和滚动空间容易需要额外维护，布局会变得脆弱。
