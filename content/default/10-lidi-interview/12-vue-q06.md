# Vuex 和 Pinia 有什么区别？

## 核心回答

1. 两者都可以管理跨组件和跨页面状态。Vuex 的结构更固定，通常有 state、getters、mutations 和 actions；Pinia 的 API 更直接，TypeScript 支持也更自然。
2. Vue 2 的智服工单使用 Vuex，方便集中管理登录会话和工单相关状态；Vue 3 项目更适合使用 Pinia 的 store 组织状态。
3. 不是所有状态都要放进去。页面表单、弹窗和图表临时配置，通常放在组件内部更简单。
4. 选择时还要看团队已有项目和生态，不会为了追求新技术强行替换现有状态管理方案。
