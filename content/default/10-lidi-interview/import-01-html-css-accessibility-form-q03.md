# 错误提示要不要用 alert？

## 核心回答

页面级的重要错误可以用 aria-live 区域播报，但不要每个字段变化都触发强提醒。视觉提示、焦点位置、读屏文本三者要一致，用户才能知道哪里错、下一步怎么改。
