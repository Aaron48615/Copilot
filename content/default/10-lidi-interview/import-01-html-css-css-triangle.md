# 用 CSS 画一个三角形？

## 核心回答

1. 最常见的办法是利用边框交界的形状，把元素内容宽高设为零，让左右边框透明，只给下边框颜色，就能得到朝上的三角形。原因是相邻边框在角部斜向相接，内容区消失后，保留的一侧边框呈现出三角区域，而不是 CSS 有一个专门的三角标签。

2. 例如 `width: 0; height: 0; border-left: 8px solid transparent; border-right: 8px solid transparent; border-bottom: 8px solid currentColor` 可以画小箭头。这里左右各 8px 决定底边总宽，下边框厚度决定高度；下边框有色对应尖角朝上，容易把方向背反。

3. 提示框的小尾巴可以放在 before 或 after 上，让父级提供定位参照。它是装饰，不应该成为唯一的状态说明；如果箭头表示展开收起，还需要按钮名称与展开状态，不能让用户只能靠一个三角朝向猜测当前界面。

4. 形状更灵活时可以用 clip-path 的 polygon，复杂描边和可缩放图标也可以用 SVG。边框法简洁，但阴影、圆角和精确描边不太方便；我会根据设计复杂度选择，并检查缩放和不同像素密度下的边缘，不为一个小装饰堆很长的 CSS。

5. 还要区分可见形状与盒子范围，透明边框虽然看不见，仍参与边框盒尺寸计算。把箭头放进按钮时，我会让按钮本体提供足够的点击区域，箭头只作装饰，避免用户必须精确点中几像素的小尖角才能操作。

## 追问：怎样给边框三角形做一圈描边？

1. 常见做法是叠两层三角形，底层稍大并使用描边色，上层稍小并使用填充色。二者的方向和中心线要一致，通过一点位置差露出底层边缘，视觉上就像有描边，但它本质上不是普通 border 环绕路径。

2. 这个方法适合背景颜色明确、尺寸变化不多的小箭头。若背景是渐变或透明内容，内层填充可能不能自然衔接；缩放时描边粗细也不一定完全均匀，需要按实际尺寸观察，不能假定所有方向效果一致。

3. 如果设计要求精准的描边、圆角或复杂阴影，我会考虑 SVG 路径，直接控制填充与描边更清楚。选择时衡量维护复杂度，两个伪元素可以完成的小装饰不必过度设计，但也不要为了坚持纯 CSS 牺牲视觉正确性。

## 追问：clip-path 画三角形和边框法有什么区别？

1. clip-path 通常先有一个正常宽高的盒子，再用百分比坐标裁出多边形，例如顶部中点和底部两个角。它比较直观，也能裁切图片或渐变背景，而边框法主要利用不同颜色的边框区域形成形状。

2. 裁切只改变呈现区域，不会让普通文档流按三角外形重新排版，布局仍然依据原来的盒子。若想让正文沿形状环绕，需要另外考虑相应的形状排版能力，不能以为裁成三角后周围文字也会自动贴边。

3. 我会检查被裁掉的内容是否仍符合交互预期，以及阴影和边框是否需要额外包装。简单提示箭头可以选择更少的规则，装饰图形则按填充和缩放需求选择；两种方案没有脱离场景的绝对优劣。
