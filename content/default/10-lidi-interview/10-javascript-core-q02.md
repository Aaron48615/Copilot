# 什么是闭包？项目中哪里用到了？

## 核心回答

1. 闭包可以简单理解为：函数即使离开了原来的作用域，仍然可以访问创建它时的变量。
2. 防抖函数就是一个典型例子。外层函数保存定时器，返回的事件处理函数每次调用时都能访问并修改这个定时器。
3. 闭包也可以用来保存模块内部状态，避免变量暴露到全局。但如果闭包长期持有很大的对象，也可能让对象不能及时被垃圾回收。
4. 所以我不会只说闭包是“函数套函数”，还会注意它保存了什么数据、生命周期多久，以及是否需要主动清理定时器或监听器。
