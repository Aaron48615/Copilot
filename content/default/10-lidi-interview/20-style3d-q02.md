# React 里面怎么做 3D？

你如果用过 React Three Fiber，可以说：

“React 项目里可以直接使用 Three.js，也可以用 React Three Fiber。R3F 相当于用 React 的组件化方式来组织 Three.js 场景，可以通过组件和 Hooks 管理模型、相机、灯光以及交互，对 React 项目会更自然一些。”

这个程度对前端实习已经够用了。
