# 如何让一个元素水平垂直居中？

## 核心回答

1. 先分清要居中的是文字、单个盒子，还是一组子元素，父容器有没有可分配的宽高。普通文字水平居中可以用 `text-align`，但它不会把一个任意块级盒子本身挪到中间，更不管垂直方向。几种「居中」不是一回事。

2. 普通组件里 Flex 比较顺手：父元素 `display: flex; justify-content: center; align-items: center`。默认主轴横向时，两个方向都能居中。父元素至少要有合适的高度或最小高度，内容跟容器一样高，垂直对齐看不出来。

3. 外层已经是 Grid，父容器可以 `place-items: center`，子项在各自网格区域里居中；只调其中一个，就在那个子项上 `place-self: center`。定宽的普通块只要水平居中，左右 `margin: auto` 也行，但盒子宽度得小于可用宽度，两侧才有剩余空间可分。

4. 覆盖式内容可以用绝对定位加百分比再平移：先走到包含块中心，再减去自身宽高的一半。不必事先知道具体尺寸，但退出了正常布局，父容器高度和溢出得另管。多行文案、窄屏、字体放大后都要看一眼。

5. 还有视觉中心和几何中心的差别。图标文件里面带着透明留白，盒子已经居中了，图形仍可能偏一边。先看资源实际边界，再决定要不要微调，别用一堆偏移去盖错误的图片留白。

## 追问：text-align: center 为什么不能让整个 div 居中？

1. `text-align` 管的是块容器里面行内内容怎么齐，比如文字、行内元素、行内块。div 里的字可以在中间，div 这个块盒子还是按自己的宽度和外边距参与父容器布局。

2. 这个 div 有合适宽度，左右 `margin: auto`，剩余空间会分到两边。宽度还是 auto、铺满父容器，盒子本来就已经占满整行，「挪到中间」看不出变化。

3. 还要垂直方向，或者好几个子项一起排，改用父级 Flex 或 Grid。先弄清对齐的是谁、处在哪种布局，再挑属性，比父子都加 `text-align` 好维护。最后用轮廓看盒子边界，别把文字居中当成整个容器居中。

## 追问：用 transform 居中时，动画为什么会把居中位置弄丢？

1. 居中平移和动画可能同时改 `transform`，一个元素最终只有一套算完的变换。原来是 `translate`，悬浮时直接改成 `scale`，平移就被盖掉，元素自然离开原来的中心。

2. 一种做法是平移和缩放写在同一条声明里，各状态都把平移留着；另一种是外层负责定位居中，内层负责动画。动效多的时候后一种更清楚，不用每个关键帧都重复维护定位变换。

3. 还要看 `transform-origin` 和放大之后有没有溢出。几何中心对齐了，动画内容也不一定一直在可视范围内，靠边弹层、放大的卡片尤其容易。按实际尺寸和交互状态验，别只看静止那一帧。
