# ES6+ 有哪些常用新特性？

## 核心回答

ES6+ 新增了不少语法,我主要从几个方面来说。

首先是变量声明方面,新增了 `let` 和 `const`,它们是块级作用域,解决了 `var` 存在的变量提升和全局污染的问题。我现在写代码基本不用 `var`,默认用 `const`,需要重新赋值的场景才用 `let`。

然后是箭头函数,语法更简洁,而且它不绑定自己的 `this`,会继承外层作用域的 `this`。比如在写事件处理函数的时候,用箭头函数就不用手动 `bind(this)` 了。

还有模板字符串,用反引号加 `${}` 来做字符串拼接,写起来更直观,也支持多行。

解构赋值也是常用的一个特性,可以从数组或对象里直接取值,比如从接口返回的数据里取字段,或者从 props 里解构出需要的属性,代码会简洁很多。

展开运算符 `...` 和剩余参数也很常用,比如做数组、对象的合并,或者在 immutable 更新状态的时候,像 `{...state, name: 'new'}` 这种写法就很方便。

异步方面,ES6 引入了 Promise,解决了回调地狱的问题;后面 ES2017 又加入了 async/await,它是基于 Promise 的语法糖,让异步代码可以写得像同步代码一样,可读性更好。

模块化方面,ES6 也提供了原生的 `import`/`export` 语法,不用再依赖 CommonJS 或者第三方模块加载器。

除此之外还有一些我了解但用得相对少一点的,比如 `Map`/`Set`、可选链 `?.`、空值合并 `??`,还有 `class` 语法糖。

总的来说,ES6+ 这些特性一部分是让代码更简洁安全,比如块级作用域;另一部分是解决异步和模块化上的痛点,比如 Promise 和 ES Module。这些也是我在实际项目里比较常用的。
