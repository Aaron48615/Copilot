# 城市视图中的地图和 3D 数据柱是怎么实现的？遇到性能问题怎么办？

## 核心回答

1. 地图部分使用高德地图 JS API，根据当前城市和环境模式动态绘制标记点以及空气质量覆盖层。地图实例由组件管理，城市或筛选条件改变时更新数据和覆盖物。
2. 3D 部分使用 React Three Fiber，把人口、面积和 GDP 等数据映射成柱子的高度或颜色，支持不同指标切换。
3. 这类第三方实例不能只考虑“能显示”，还要考虑初始化时机、数据更新、组件卸载和重复实例问题。
4. 如果地图或 3D 页面变慢，我会先用 Performance 和 Network 面板确认瓶颈是在资源加载、数据处理、渲染还是频繁更新，而不是一上来就盲目减少功能。
5. 可以采用按需加载、减少一次性标记数量、聚合地图点、限制 3D 场景复杂度、降低不必要的 React 更新等方式改善体验。
