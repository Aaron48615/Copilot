# 常见的 HTTP 状态码有哪些？

常见的 HTTP 状态码我一般会按类别来记。

`2xx` 表示请求成功。

比较常见的是 `200`，表示请求正常成功；`201` 表示资源创建成功，比如新增一条数据；`204` 表示请求成功，但是响应体没有内容。

`3xx` 主要和重定向有关。

比如 `301` 是永久重定向，`302` 是临时重定向，`304` 表示资源没有修改，可以继续使用浏览器缓存。

`4xx` 表示客户端这边的问题。

`400` 是请求参数或者请求格式有问题；`401` 一般表示没有登录或者身份认证失败；`403` 表示已经识别到用户身份，但是没有权限访问；`404` 就是请求的资源找不到了。

这里 `401` 和 `403` 比较容易混，我一般理解为：`401` 偏向“你是谁还没认证成功”，`403` 是“知道你是谁，但是你没有权限”。

`5xx` 表示服务端出了问题。

最常见的是 `500`，表示服务器内部错误；`502` 一般是网关从上游服务器拿到了错误响应；`503` 表示服务暂时不可用，可能是服务维护或者当前负载比较高。

前端开发里我平时接触最多的基本就是 `200`、`400`、`401`、`403`、`404` 和 `500`，像 Axios 响应拦截器里也经常会根据这些状态码做统一处理。
