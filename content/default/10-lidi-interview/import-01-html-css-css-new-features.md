# CSS3 有哪些新特性？

## 核心回答

CSS3 相比以前主要增加了很多布局、视觉效果和动画相关的能力。
比较常用的有：

- `Flex` 和 `Grid` 布局；
- `border-radius` 圆角、`box-shadow` 阴影；
- `linear-gradient` 渐变；
- `transform` 做旋转、缩放、位移；
- `transition` 做过渡动画；
- `animation` 配合 `@keyframes` 做更复杂的动画；
- `media query` 媒体查询，用来做响应式布局；
- 还有一些新的选择器，比如 `:nth-child()`、属性选择器等。

实际开发里我用得比较多的是 Flex、媒体查询、transition 和 transform。

另外在 JavaScript 操作 DOM 时，我也经常用 `querySelector` 和 `querySelectorAll` 通过 CSS 选择器来获取元素，不过它们属于 DOM API，不算 CSS3 本身。

## 追问：CSS 自定义属性和预处理器变量有什么不同？

1. 预处理器变量通常在构建时被替换，浏览器拿到的是计算后的 CSS。自定义属性存在于运行时层叠中，通常会继承，可以按页面区域或主题状态改变，所以很适合需要在使用过程中切换的颜色和尺寸。

2. 例如给根元素定义主题色，在某个面板内覆盖同名属性，里面使用 var 的按钮就能获得局部主题。这样不必为每个组件生成一份深色选择器，但要考虑变量命名、默认值和覆盖范围，避免意外影响其他区域。

3. 两者也可以同时用：构建时生成稳定的尺寸列表，运行时用自定义属性表达用户可切换的主题。我不会把原生变量当成所有 Sass 逻辑的替代品，循环生成规则、模块组织等需求还要单独评估。

## 追问：采用新 CSS 特性时，怎样安排降级？

1. 先写能完成基本阅读和操作的基础样式，再用能力检测包住增强规则。比如容器查询不可用时保留单列卡片，支持时改成更紧凑的横向排列，用户得到的精细程度可以不同，主要功能不能依赖增强才能出现。

2. 我会检查项目支持的浏览器版本和 WebView 环境，必要时用 `@supports` 判断语法支持。检测通过也不是完整行为测试，复杂布局仍需要在实际环境里跑一次，尤其是不同特性组合后的滚动与定位表现。

3. 选择降级方案时也要控制维护成本。如果一个小装饰需要大量兼容代码，可以接受更简单的视觉表现；若涉及核心布局，就应提供清晰的替代方式，不能让“用了新技术”成为内容重叠或按钮不可达的理由。
