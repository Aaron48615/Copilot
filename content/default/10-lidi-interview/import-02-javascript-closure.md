# 什么是闭包？项目中使用过吗？

## 核心回答

1. 闭包就是：里面的函数还能用外面的变量，哪怕外面那个函数已经跑完了。不一定非要 `return` 一个函数。`setTimeout`、点击回调，只要里面用到了外面的变量，就是闭包。

2. 最常见是防抖。外面存一个 `timer`，返回的函数每次先清掉上一次，再重新计时。几次输入共用同一个 `timer`，才能把连续输入合成一次。如果每次都是新的 `timer` 变量，上一回就取不消。

3. 轻购搜索页就是这样：输入防抖里存了联想请求的定时器，组件卸掉时清定时器、取消旧请求。闭包拿到的也不是当时拍下来的照片，外面那个变量后来改了，里面再读会读到新的。

4. 闭包本身不会漏内存。真正麻烦的是函数一直还在，比如监听没摘，还握着一个很大的列表。页面都走了监听还在，列表就卸不掉。先看这个函数还被谁拿着，别一看到闭包就觉得代码有问题。

## 追问：为什么循环里的定时器可能输出同一个值？

1. `var` 写循环变量，几个定时器共用这一个。等定时器真正跑的时候，循环已经结束，读到的就是最后那个值，所以经常全打印成 `3`。

2. 循环里改成 `let`，每一圈有自己的变量，回调就能打出 `0`、`1`、`2`。也可以包一层函数，把当前数字当参数传进去，效果类似。

3. 要是几个回调共用同一个对象，换成 `let` 也不会把对象里面的内容拷一份。改对象属性，大家还是能互相看到。

## 追问：闭包保存变量为什么还会遇到旧值问题？

1. 闭包一直抓着它当初那份变量。如果当时已经把文案拼好了，再返回一个打印函数，后面就算把计数改了，打印的还是那句旧文案。

2. 每次渲染都会产生新的局部变量。早先注册的回调还连着上一轮的，不会自动改去读这一轮的同名变量。所以要搞清楚回调是哪一次留下来的。

3. 要最新值，就在执行的时候再读，或者重新注册回调。有些情况反而该留旧值，比如请求发出去时的关键词，回来还得对上当时搜的那次，不能偷偷换成后来输入的。
