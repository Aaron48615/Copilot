# 数组扁平化怎么写？

## 核心回答

1. 允许用标准库的话，先写 `list.flat(depth)`，默认只展开一层，要全部展开就传 `Infinity`。扁平化返回新数组，但不会深拷贝里面的对象，原来那些普通对象还是同一份引用进结果。

2. 手写时先限定输入是没有循环的普通嵌套数组，做完全展开。用一个结果数组攒叶子值，碰到数组继续往里走，别在递归里反复 `concat` 已有结果，那样会一次次复制。

    ```js
    function flatten(list) {
      const result = [];
      function visit(array) {
        for (let i = 0; i < array.length; i++) {
          if (!(i in array)) continue;
          const item = array[i];
          if (Array.isArray(item)) visit(item);
          else result.push(item);
        }
      }
      visit(list);
      return result;
    }
    ```

3. 比如 `[1, [2, [3]], 4]` 从左到右得到 `[1, 2, 3, 4]`，空数组不加元素。`i in array` 用来跳过不存在的索引，显式放进去的 `undefined` 会留下来，这两件事不是一回事。

4. 普通、没有共享的嵌套数组，耗时跟访问过的各层索引总数有关，结果空间跟输出元素数有关，调用栈深度跟嵌套层数有关。很深的输入可能超过调用栈限制，`flat(Infinity)` 也不代表无限资源随便用。

5. 这段是教学版，不是完整的 `Array.prototype.flat` 替代品，没有深度参数、类数组调用、数组子类构造这些标准行为。题目只要展开两层，就得加剩余深度判断，不能直接交完全展开版。数据可能自引用的话，得另外约定报错或处理方式，不能一路递归到程序挂掉。

## 追问：嵌套太深时，如何用显式栈保持展开顺序？

1. 用栈保存「当前数组和下一个待访问索引」，一开始只有最外层。每次看栈顶：访问完了就弹出，否则先推进索引，再处理当前位置。这样不再靠函数递归调用栈。

2. 碰到嵌套数组就压新栈帧，碰到普通值就推进结果，缺失索引继续跳。始终先把当前子数组处理完，再回到父数组下一个位置，从左到右的输出顺序自然就在，最后不用反转。

3. 栈帧数量跟嵌套深度有关，但结果数组照样要占内存，巨大输入也可能把页面卡住。如果只是一批批消费元素，可以再考虑生成器或分批；显式栈只解决递归深度，别的资源限制还在。

## 追问：数组空槽、undefined 和循环引用分别怎么处理？

1. 空槽表示这个索引不存在，比如 `[, 1]`；`[undefined, 1]` 的第零项是真有的。标准 `flat` 在展开的那几层会跳过空槽，显式的 `undefined` 会留下；没继续展开的嵌套数组里面，空槽可能还在。

2. `for...of` 扫数组时可能把空槽读成 `undefined`，直接拿它替换教学代码里的索引检查，结果会变。稀疏数组单独当样例看，普通整数数组过了，不能说行为和标准库一样。

3. `a.push(a)` 这种循环，可以记当前递归路径上的数组，重复走进去就报不支持循环。别拿一个全局集合把所有重复数组都跳过，因为 `[sub, sub]` 是合法共享引用，通常应该把内容展开两遍。
