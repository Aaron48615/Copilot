# CLS 怎么从代码里预防？

## 核心回答

图片、视频和广告容器提前留尺寸，异步内容尽量在预留区域里替换；字体加载要考虑回退字体的尺寸差异。不要在用户操作后突然把已有内容整体插到上面。
