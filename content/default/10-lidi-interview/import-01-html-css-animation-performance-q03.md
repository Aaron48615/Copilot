# 移动端为什么更容易卡？

## 核心回答

设备 CPU、GPU 和内存都可能更有限，长列表、高清图片、复杂阴影同时出现时更明显。需要减少同时动画的节点、压缩资源、限制列表渲染量，并在真实设备上验证。
