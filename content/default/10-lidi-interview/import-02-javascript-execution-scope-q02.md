# 变量环境和词法环境需要背到什么程度？

## 核心回答

面试里我会说明它们用于描述不同声明和环境记录，重点放在能解释现象：let 的 TDZ、函数声明提升、闭包和块级作用域。不会把规范内部字段当成业务代码细节；如果题目追到规范，再结合一个最小例子说明创建和查找顺序。
