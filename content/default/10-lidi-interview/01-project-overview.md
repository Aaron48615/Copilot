# 请介绍一下你做过的项目，哪个项目最值得展开？

## 核心回答

1. 我目前主要做过三个个人项目。轻购是 Vue 3 和 TypeScript 开发的移动端电商平台；城市视图是 React 和 TypeScript 开发的城市数据可视化平台；智服工单是 Vue 2 开发的企业售后工单系统。
2. 轻购的代码里有首页、分类、搜索、商品详情、购物车、地址、订单确认、订单列表、登录注册和轻购AI。用户可以从浏览商品一直走到提交订单，流程比较完整。
3. 我最想展开轻购里的 AI 功能。轻购AI允许用户用自然语言说预算、用途和偏好，前端调用 `/guide/recommend` 后，把接口返回的意图、推荐商品、匹配条件和暂时没有明确结果的条件分别展示出来。
4. 轻购还有搜索联想和商品详情 AI 卖点，这两条链路的实现方式不同：搜索联想重点是防抖、取消旧请求、请求编号和本地降级；商品卖点重点是等待商品基础信息加载后再生成，并保留本地卖点作为备用。
5. 轻购最能体现我的地方，是我能把页面、路由、请求封装、Token、AI 结果、SKU、购物车和订单状态串起来讲清楚。它是个人项目，所以我也会诚实说明还没有经历多人协作和正式线上测试。
