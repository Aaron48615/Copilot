# 手写题写不出来怎么办？

## 核心回答

1. 我会先把输入、输出和最小例子写出来，把问题拆小。
2. 如果暂时想不起最优写法，会先写一个能工作的版本，再说明可以从时间复杂度或空间复杂度上改进。
3. 我会边写边讲思路，让面试官知道我不是完全没有方向。
4. 代码题最重要的是正确性、边界意识和沟通，不是一定要写出最短的代码。
