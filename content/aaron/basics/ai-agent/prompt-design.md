# Prompt（提示词）是什么

## 核心回答

Prompt 是提供给模型的输入和指令集。好 Prompt 的价值不是“发明神奇口令”，而是减少任务歧义，让模型知道成功标准和行动边界。

一个实用 Prompt 通常包含：

- **目标**：要完成什么。
- **上下文**：现状、用户、技术栈和已知信息。
- **约束**：不能改什么，必须兼容什么，哪些操作要确认。
- **输出格式**：代码、JSON、表格还是简短结论。
- **验收标准**：什么结果算完成，需要运行哪些验证。
- **必要示例**：当文字规则仍有歧义时，给少量输入/输出样例。

```text
请修复商品列表快速滚动时的白屏。

上下文：React + TypeScript，当前使用固定高度虚拟列表。
约束：不更换虚拟列表库，不改 API，不重构无关组件。
验收：快速滚动时无空白，现有测试通过，并增加覆盖过扫缓冲区的测试。
先定位原因，再做最小修复并说明验证结果。
```
