# HTML5 新增了哪些能力

## 核心回答

H5中新增了一些新的语义化标签，比如header, footer, nav, article, section等等，在原有的基础上又丰富了一些。还有表单控件，比如time, date, email, url, search，让表单的功能变得更全面了。H5还新增了本地存储loaclStorage和sessionStorage。选择器querySelector和querySelectorAll。还新增了JSON字符串和JS对象互转的方法，JSON.parse是JSON字符串转JS对象，JSON.stringfy是JS对象转JSON字符串。H5还新增了音频视频的api，audio和video，在此之前，想在页面里插入视频一般会用flash插件。H5还新增了画布api，Canvas。与SVG不同，Canvas是新增的H5元素，放大会失真，而SVG是可伸缩矢量图形，放大缩小都不失真。
