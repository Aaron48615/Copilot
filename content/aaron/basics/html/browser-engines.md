# 你对浏览器内核的理解

## 核心回答

浏览器内核主要是分为渲染引擎和JS引擎。渲染引擎负责渲染页面内容，默认可渲染HTML、XML、图片，也可以借助第三方插件渲染PDF等。JS引擎负责解析并执行JS代码，实现网页动态效果。

常见的内核有IE内核、Chrome内核（用的Blink和JSv8）、Firefox内核（用的Gecko和SpiderMonkey）、Safari的Webkit内核，Opera的Blink内核。还有的浏览器，比如360用的是IE加Chrome双核的。
