# 你对 HTML 语义化的理解

## 核心回答

HTML语义化是使用合适的标签表达合适的内容，比如用p标签代表段落，用article标签代表正文。这样是为了在页面没有样式的时候也能保持基本结构。对开发者来说，这样能更容易理解代码、维护代码。对机器来说，有利于SEO，也就是搜索引擎优化，便于让一些读屏软件或搜索引擎能更好地理解页面，也便于爬虫爬取网页上的有效内容。H5里也新增了一些语义化标签，比如header、footer、nav、article、section等。
