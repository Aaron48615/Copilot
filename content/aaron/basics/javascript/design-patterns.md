# 你了解哪些设计模式

## 核心回答

我了解的有单例、工厂、观察者、代理和装饰器模式。单例是在约定范围内共用一个实例，比如统一管理配置；工厂是把对象的创建过程集中起来，根据条件生成不同对象，调用方不用知道每一步怎么创建。

观察者模式是一个对象变化时通知依赖它的观察者，适合状态变化后联动处理。代理是在访问目标前后加一层控制，比如缓存、访问检查；装饰器是保持原来功能的同时逐层增加能力，比如给一个函数加日志和计时。

我更倾向于先看重复逻辑和变化点，再用合适的模式整理，不会为了用模式而增加很多层封装。

【观察者和发布订阅很接近，但发布订阅通常多一个事件中心，发布者和订阅者不用直接互相持有；装饰器模式是一种设计思路，不等于必须使用某种 @ 装饰器语法。】
