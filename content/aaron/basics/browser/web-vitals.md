# LCP、INP、CLS 分别反映什么问题？

## 核心回答

把它们对应到使用页面时的感受，就比较好理解了。LCP 看主要内容什么时候出现，比如首屏的大图或文本；INP 看点击、输入以后页面响应得怎么样；CLS 看页面有没有突然移位，比如图片出来时把按钮挤走了。

LCP 不好，可以查主图是不是太晚才开始加载，接口或页面返回是不是慢。INP 不好，就看主线程有没有长时间计算、事件处理是不是太重。CLS 就先查图片有没有预留尺寸，异步内容插入时有没有把原来的布局推开。

我比较喜欢把指标和性能面板放在一起看。指标能指出大概是哪种问题，时间线能看到具体卡在哪一步，比只说“感觉慢”或者只盯一个分数更容易找到原因。改完再比较，看看用户等待的地方有没有改善。
