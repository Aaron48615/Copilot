# 瀑布流布局怎么实现

## 核心回答

瀑布流通常是每列宽度相近，但卡片高度不同，新卡片放到当前最短的一列，减少大块空白。用 JavaScript 实现时，先根据容器宽度、列宽和间距算出列数，维护每列的高度；每放一个卡片，就找到最短列，计算坐标并更新那一列高度，父容器高度取最大列高。

图片尺寸会影响计算，所以可以提前知道宽高比来预留高度，或者在加载后重新排布。窗口变化时也要重新计算列数，但可以做防抖，避免每次 resize 都完整重排。

CSS 多列布局也能做出类似外观，写法简单，但内容顺序主要是先沿列排列；普通 Grid 不会自动按最短列排成瀑布流，可能需要额外计算、对应能力或组件库。选择时我会一起看视觉效果、阅读顺序和交互要求。
