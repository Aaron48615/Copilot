# 移动端适配是怎么做的？

## 核心回答

移动端先设置好 viewport，让页面按设备宽度布局。具体排版上，我更喜欢用 Flex、百分比这些能随空间调整的方式，所有尺寸都写死的话，换个屏幕就容易挤在一起。屏幕宽度变化比较大时，可以用媒体查询调整列数、间距，或者把横向排列改成纵向排列。

rem 是根据根元素字号换算尺寸，vw 是根据视口宽度换算，它们都能帮助适配，但不是换了单位就什么都解决了。比如一段很长的文字、横屏、用户把字号调大，这些还是得看实际布局。

实际检查时，重点看窄屏有没有横向滚动，按钮是不是太挤，键盘弹出后输入框会不会被挡住。底部固定按钮还要考虑手机安全区。我觉得适配有没有做好，还是得看换个屏幕以后能不能看清、能不能顺畅操作。
