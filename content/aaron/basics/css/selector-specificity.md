# CSS 选择器优先级怎么判断

## 核心回答

我会先看两条规则是不是作用在同一个元素的同一个属性上，再看层叠规则。最常见的场景是同一来源、同一层级的普通样式，这时内联样式通常优先于样式表；样式表内部再按 ID、类和属性及伪类、标签和伪元素的数量逐级比较，相同才看谁写在后面。

比如一个 ID 的权重不会被很多个类选择器简单“加分超过”。通配符和空格、>、+、~ 这些组合关系本身不增加权重。外部 CSS 和 style 标签也没有谁天然更高，要看选择器以及加载后的声明顺序。

【!important 属于重要性判断，不是选择器权重里额外加一分；来源、层叠层和动画等也会影响最终结果。:where() 的权重是 0，:is()、:not()、:has() 主要取参数中最高的选择器权重。直接作用于元素的声明，也不能拿祖先继承过来的值简单按选择器权重比较。】
