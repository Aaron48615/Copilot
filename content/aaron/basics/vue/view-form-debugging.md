# 项目出现视图不更新、报错或动态表单校验问题，怎么排查

## 核心回答

如果遇到这种问题，我会先稳定复现，再看 Console 的报错位置和 Network 的返回内容，确认是数据没拿到、代码没执行到，还是数据变了但界面没有更新。比如读取 undefined 上的 prototype，重点是沿调用栈查哪个变量或导入没有得到预期值，不能只根据错误文字猜一个固定原因。

视图不更新时，我会检查数据是否响应式、有没有改错对象、是不是还没等到 DOM 更新，以及旧请求有没有覆盖新结果。Vue 2 新增属性和数组索引修改，也要考虑 $set、splice 或替换对象。

动态表单则要看校验项的 prop 能不能从整个 form model 中找到字段。比如模型是 form.list，校验路径通常需要写成 `list.${index}.name`，而不是把循环里的局部变量名 item.name 当成完整路径。增删项之后，还要检查索引和旧的校验状态。

【这是排查思路和示例，实际面试讲“自己遇到过什么”时，要换成真实经历，并交代现象、定位过程和验证结果，不把示例当作已经发生过的工作经验。】
