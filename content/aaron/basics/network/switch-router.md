# 交换机和路由器有什么区别？

## 核心回答

传统二层交换机根据 MAC 地址表在局域网内转发数据帧；路由器根据 IP 路由表连接不同网络、转发数据包。现实设备可能同时提供多层交换和路由能力，不能只按设备名称绝对划分。
