# 请做一下自我介绍

我可以结合具体模块，介绍页面交互、接口处理和实现时遇到的问题。

拾光集主要使用 Vue 3 和 TypeScript；映刻影视使用 uni-app 和 Vue 2；云枢使用 React、TypeScript 和 Redux Toolkit，并接入图表与地图相关库。
