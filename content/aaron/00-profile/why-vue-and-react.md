# 为什么同时学 Vue 和 React？哪个更熟？

## 核心回答

现有项目里，拾光集用 Vue 3，映刻影视用 Vue 2 和 uni-app，云枢用 React。接触不同写法，可以比较组件怎么拆、状态怎么更新，以及逻辑怎么复用。

加入团队后会跟着项目技术栈走。框架语法有差别，但接口处理、组件职责和状态设计这些问题是相通的。

## 追问：维护 Vue 2 项目要注意什么？

先理解现有 Options API 的组织方式，以及新增对象属性、数组更新等响应式限制。改一个功能时不必连带重写整套结构，应该根据需求和验证成本决定范围。
