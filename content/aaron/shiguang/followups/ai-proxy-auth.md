# 追问：AI Key 藏到服务端以后就安全了吗？别人直接请求 /api/ai 怎么办？

## 核心回答

还不够。Key 放服务端只是避免直接给浏览器，别人仍然可能直接请求 `/api/ai` 消耗额度。现在已经检查 POST、JSON、浏览器同源、请求体大小、提示词长度和模型，也有基础 IP 限流，但这些不等于验证商城用户身份。

继续完善的话，我会补用户鉴权，再设置用户额度、IP 额度和全站费用上限。

【也可以只接收业务类型、商品 ID 或短关键词，由服务端拼提示词，减少被当成通用聊天接口的可能。现在上游必须是 HTTPS，输出最多 300 tokens，上游错误也做了简化，分别用来限制调用地址、控制单次输出和减少内部信息暴露。】

## 回答要点

- 还不够。Key 放服务端只是避免直接给浏览器，别人仍然可能直接请求 `/api/ai` 消耗额度。
- 继续完善的话，我会补用户鉴权，再设置用户额度、IP 额度和全站费用上限。
- 也可以只接收业务类型、商品 ID 或短关键词，由服务端拼提示词，减少被当成通用聊天接口的可能。
