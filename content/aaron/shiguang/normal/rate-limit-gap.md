# 不足一：AI 限流还不是全站配额

## 核心回答

AI 现在虽然有限流，但计数是存在内存 Map 里的，只对当前实例有效。Serverless 如果同时跑了多个实例，它们的计数不共享，实例重启也会丢，而且现在还没有按商城登录用户来做 AI 鉴权。

后面我会考虑把计数放到 Redis 这类共享存储里，用原子操作处理并发，再分别限制用户、IP 和全站的用量。

【目前已经有每分钟、每小时的 IP 次数限制，但这和全站费用上限不是一回事。共享计数和用户额度是我后面想补的，还没实现。】

## 回答要点

- AI 现在虽然有限流，但计数是存在内存 Map 里的，只对当前实例有效。
- 后面我会考虑把计数放到 Redis 这类共享存储里，用原子操作处理并发，再分别限制用户、IP 和全站的用量。
- 目前已经有每分钟、每小时的 IP 次数限制，但这和全站费用上限不是一回事。
