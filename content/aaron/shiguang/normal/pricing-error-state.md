# 不足四：购物车计价失败后，结算按钮状态不够完整

## 核心回答

购物车这里还有个状态没处理好。计价失败后现在会把金额清零，并结束 loading，但结算按钮主要看有没有选商品、是不是在计算，所以失败以后仍然可能点进去，也容易让用户把 0 当成真实金额。

我会把计价明确分成未计算、计算中、成功和失败。只有最新一次计价成功，而且选择没变化，才允许结算；失败时显示“价格暂不可用”，再给一个重试入口。

【虽然确认订单页还会向服务端核价，但不能因此忽略购物车的反馈，这一页也应该让用户看明白当前是什么情况。】

## 回答要点

- 购物车这里还有个状态没处理好。计价失败后现在会把金额清零，并结束 loading，但结算按钮主要看有没有选商品、是不是在计算，所以失败以后仍然可能点进去，也容易让用户把 0 当成真实金额。
- 我会把计价明确分成未计算、计算中、成功和失败。
- 虽然确认订单页还会向服务端核价，但不能因此忽略购物车的反馈，这一页也应该让用户看明白当前是什么情况。

## 面试官可能追问

- 为什么金额显示 0 不能替代计价失败状态？
- 选择变化后，上一次成功计价还能允许结算吗？
