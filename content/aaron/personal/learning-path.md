# 为什么学了 uni-app，又学 React、Vue 3，学习路线是不是不太连贯？

## 核心回答

其实我在学小程序之前就学过 Vue 2，也做过一个以增删改查为主的小项目，主要是练数据展示、表单操作和接口请求。后来做 uni-app 小程序，选的也是 Vue 2 版本，所以这一段是接着前面的基础往下学的，不是直接跳到一个完全陌生的技术上。

小程序这个阶段，我想练的是把几个页面连成一个完整流程。比如首页进列表、列表分页、再进详情，除了把数据拿回来，还要考虑页面传参、组件复用和交互这些问题。

后来学 React，是想了解另一种组织组件和管理状态的方式。我也不想只停在看语法，所以就拿云枢来练，把地图、图表、登录权限这些内容串起来。再学 Vue 3，其实也是回到之前的 Vue 基础上，继续理解组合式 API，并用商城这种比较熟悉的场景做完整练习。

所以看简历会觉得框架换了几次，但我一直在练的还是组件、状态、接口和页面交互，只是项目场景和实现方式不同。我觉得对比着学有帮助，不过也不能因为接触过几个框架，就说自己每个都很熟。我更希望把项目里真正用到的东西弄明白，能解释为什么这么写，以及哪里还可以改。
