# 单页应用和多页应用有什么区别？

## 核心回答

SPA 在页面切换时通常由前端路由更新界面，不必重新加载整份 HTML。MPA 则有多个页面入口，跳转时会请求另一份页面。

SPA 可以保留页面间的状态，但要注意首屏脚本体积和客户端路由刷新。MPA 更容易按页面独立组织，但整页跳转也会重新加载页面环境。SEO 还要看实际返回的 HTML 和渲染方案，不能只凭单页、多页就下结论。

## 追问：SPA 刷新子路由为什么会 404？

浏览器会直接向服务器请求这个路径。如果服务器只按静态文件查找，就可能找不到。需要给前端页面路由配置回退入口，同时保留 API 和静态资源自己的路由规则，避免把错误请求也返回成 HTML。
