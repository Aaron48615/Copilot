# 常见的 HTTP 状态码有哪些？

## 核心回答

常见的有 200 请求成功，201 创建成功，204 成功但没有响应正文。304 表示协商缓存仍然有效，可以继续使用本地内容。

错误里要分清 401 和 403：前者是缺少有效的身份凭证，后者是服务器拒绝访问。409 表示当前资源状态有冲突，比如提交修改时版本已经过期。500 是服务端内部错误，502、504 分别常见于网关收到无效上游响应和等待上游超时。

## 追问：收到 409，页面应该怎么处理？

先按接口约定解释冲突原因。比如编辑记录时带了旧版本号，可以提示数据已经更新，让用户重新加载后确认修改。不要直接覆盖别人的更新，也不要把所有冲突都当网络问题自动重试。
